# Локализация

Поддерживаются русский и английский. Весь код локализации находится в `public/js/i18n.js`.

## Выбор языка

- Берётся первый поддерживаемый язык из `navigator.languages` по порядку предпочтения; сравнивается основная часть
  тега без учёта регистра (`ru-RU` → `ru`, `EN_gb` → `en`).
- Если ни один язык не подходит, используется английский (`FALLBACK_LANGUAGE`).
- При смене языка в браузере (событие `languagechange`) интерфейс переводится без перезагрузки.
- Ручного переключателя языка нет: это решение по требованию, см. `spec/BUSINESS_REQUIREMENTS.md`, BR-12.

## Разметка

| Атрибут                          | Что переводится |
|----------------------------------|-----------------|
| `data-i18n="key"`                | `textContent`   |
| `data-i18n-placeholder="key"`    | `placeholder`   |
| `data-i18n-aria-label="key"`     | `aria-label`    |
| `data-i18n-title="key"`          | `title`         |
| `data-i18n-content="key"`        | `content` (`<meta>`) |

Тексты по умолчанию в `index.html` английские: их видно до загрузки JS. Содержимое `<template>` тоже переводится.

## Код

- Строки: `t('key', { param })`, подстановки в шаблоне — `{param}`.
- Нет ключа в текущем языке → берётся английский; нет и там → возвращается сам ключ, в консоль пишется предупреждение.
- Даты, время и сортировка тегов используют `getLocale()` (`ru-RU` / `en-US`).
- Сообщения консоли (`console.*`) не локализуются: они для разработчика.

## Ограничения

- **id тега вычисляется без учёта локали** (`toLowerCase()`, а не `toLocaleLowerCase()`). Иначе устройства
  с разными языками могли бы получить разные id для одного тега и разойтись при синхронизации.
- `manifest.webmanifest` нельзя локализовать динамически, поэтому имя установленного приложения нейтральное — `Notes`.

## Как добавить язык

1. Добавьте словарь в `DICTIONARIES` и BCP 47 локаль в `LOCALES` в `public/js/i18n.js`.
2. Запустите тесты (`./tools/run-tests.sh`). Они проверяют, что:
   - наборы ключей во всех словарях совпадают;
   - наборы плейсхолдеров `{…}` в переводах одного ключа совпадают;
   - все ключи из `index.html` есть в словаре.
